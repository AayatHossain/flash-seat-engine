# Flash Seat Engine

A flash-sale ticketing backend that sells a limited number of seats to a very large crowd without overselling or double charging, even when parts of the system fail.

**Status:** work in progress.

## Planned stack

Java, Spring Boot, PostgreSQL, Redis, Kafka, Docker, Kubernetes, Helm, Terraform, AWS EKS, OpenTelemetry, Prometheus, Grafana, k6.
